# 公的賞与ベンチマーク Data API v1

このAPIは、`data/quantitative_benchmarks_YYYY-MM-DD.yaml` の最新スナップショットを機械利用向けに配布します。個社推定値とは分離され、公的・労使団体の集計値のみを対象にします。

## エンドポイント

GitHub Pages 配下の `/api/v1/` に以下を公開します。

- `manifest.json`: 件数、元スナップショット、SHA-256、配布物サイズ
- `benchmarks.json`: ベンチマーク全件
- `benchmarks.csv`: 表形式の主要列
- `facets.json`: publisher / metric / release_status / period の件数

## 同期方法

1. 先に `manifest.json` を取得します。
2. `distributions.<file>.sha256` が前回値と異なるファイルだけ再取得します。
3. ダウンロード後に SHA-256 を照合します。

## データ契約

- `id` はベンチマーク内で一意です。
- `release_status=first` は暫定集計です。最終集計が公表された場合も古いスナップショットを削除せず履歴として保持します。
- 金額・月数・季別・年間・集計主体が異なる行は同じ母集団とみなしません。
- `sample.workers=null` は「0人」ではなく、元資料からこの配布スナップショットで確認できないことを意味します。
- 公式一次資料へのURLは各レコードの `source_url` に保持します。

## 更新と外部負荷

通常CIは保存済みスナップショットから配布物を決定的に再生成し、連合・経団連・厚生労働省へアクセスしません。新しい公式公表を確認したときだけ、新しい日付のデータスナップショットを追加して更新します。

## 出典と利用条件

各レコードの `publisher` と `source_url` を確認してください。元資料の転載条件は各公表主体の利用条件に従います。このリポジトリは出典事実・集計値・機械配布用変換を提供し、元資料本文そのものの再配布を目的としません。
