# bonus — 日経平均採用企業の賞与制度調査

**リポジトリ:** https://github.com/KAFKA2306/bonus

日経平均株価の採用企業を対象に、賞与原資や支給額の決定方式を、公開資料の根拠とともに整理する調査プロジェクトです。

企業ごとの賞与制度を、業績連動、基本給連動、総合判断、ハイブリッドなどに分類し、確認できた事実と推定を分けて保存することを目的とします。

## 現在のデータ状態

`nikkei225_companies.yaml`は、**2024年10月1日時点の225銘柄スナップショット**です。現在の日経平均採用銘柄一覧ではありません。

READMEに以前記載されていた「30社完了」「次期70社」などの進捗値は、対応する監査済み成果物と自動集計が確認できないため削除しました。最新の調査済み社数は、`companies/`配下の実ファイルと証拠欄を集計して判断してください。

## 調査する内容

- 賞与原資の決定方法
- 営業利益、純利益、売上高などとの連動有無
- 基本給・月数との関係
- 労使交渉や会社裁量の範囲
- 対象従業員と適用期間
- 制度変更の時期
- 情報源と確認日

## 分類例

```yaml
bonus_system:
  classification: performance_linked | base_salary_linked | discretionary | hybrid | unknown
  evidence_status: confirmed | partially_confirmed | estimated | unknown
  as_of: YYYY-MM-DD
  sources:
    - title: "資料名"
      url: "https://..."
      published_at: YYYY-MM-DD
      page_or_section: "ページ・節"
```

単純なA〜Dの信頼度だけでなく、何が直接確認され、何が推定なのかを記録します。

## 情報源の優先順位

### 一次情報

- 有価証券報告書・臨時報告書
- 公式IR資料
- 統合報告書・サステナビリティ報告書
- 会社または労働組合の公式発表
- 賃金・一時金交渉の公式結果

### 補助情報

- 業界団体資料
- 信頼できる報道
- 採用情報・就業制度の公式説明

### 参考情報

- 転職サイト
- 従業員口コミ
- 掲示板・SNS

参考情報だけで制度を確定しません。複数資料が矛盾する場合は、新しい資料で上書きせず、対象年度・従業員区分・制度変更の可能性を確認します。

## 更新手順

1. 調査対象日の採用銘柄を公式な指数情報から確定する
2. 企業名、証券コード、対象年度を記録する
3. 一次資料を先に確認する
4. 賞与制度の原文とページ・節を保存する
5. 確認済み事実と推定を分離する
6. 同じ企業でも年度・従業員区分ごとにレコードを分ける
7. 集計前に重複、古い制度、出典切れを監査する

## 品質管理

- 出典URLと確認日がない分類を確定値にしない
- 「賞与○か月」と「利益の○%を原資とする」を混同しない
- 役員報酬制度と従業員賞与制度を分ける
- 連結業績と単体の労使制度を分ける
- 口コミの平均賞与額から原資決定方式を推定しない
- 現在の225銘柄と過去スナップショットを混ぜない

## 注意

賞与制度は非公開部分が多く、同じ会社でも職種、雇用区分、組合員資格、事業会社、年度により異なります。根拠が確認できない企業は`unknown`として残してください。
